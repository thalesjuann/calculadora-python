# Calculadora em Python

Projeto desenvolvido para a atividade prática da disciplina de Coding, da UNINASSAU.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Verificação de divisão por zero
- Opção para realizar outros cálculos ou encerrar o programa

## Objetivo

Praticar os conceitos básicos de Python, como variáveis, entrada de dados, estruturas condicionais e repetição.
